# GlowBop top-bar box pictures

The GLOWBOP box in the app's top bar turns over every 6 to 12 seconds. Every other turn, the side that comes up shows the next picture from this folder.

- Add a picture: put a .png, .jpg, .webp or .gif here (about 700 x 100 pixels, a wide thin strip). Every GlowBop app picks it up within an hour.
- Make it a button: add a .txt file with the same name holding one https link (for example `01-halloween.png` + `01-halloween.txt` containing `https://glowbop.com/pricing.html`). Tapping that side opens the link.
- Order: pictures play in file-name order, so start names with 01-, 02-, 03-.
- Remove a picture: delete it (and its .txt). It disappears from every app within an hour.
- No pictures here: the box just shows GLOWBOP on all four sides.
